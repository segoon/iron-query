|---|---|---|---|---|
| **IronQuery (IQ)** | (this repo) | C++17 | Code-first | Apache-2.0 |
| sqlpp11 | https://github.com/rbock/sqlpp11 | C++11/17 | Code-first | BSD-2-Clause |
| sqlpp23 | https://github.com/rbock/sqlpp23 | C++23 | Code-first | BSD-2-Clause |
| sqlgen | https://github.com/getml/sqlgen | C++20 | Code-first | MIT |
| reflect-cpp | https://github.com/getml/reflect-cpp | C++20 | Code-first | MIT |
| ODB | https://github.com/codesynthesis-com/odb | C++98–modern | Code-first | GPL-3.0 (compiler) / GPL-2.0-only or commercial (runtime libs) |
| sqlite_orm | https://github.com/fnc12/sqlite_orm | C++14 | Code-first | AGPL-3.0 |
| zxorm | https://github.com/crabmandable/zxorm | C++20 | Code-first | MPL-2.0 |
| SOCI | https://github.com/SOCI/soci | C++ (std lib) | SQL-first | BSL-1.0 |
